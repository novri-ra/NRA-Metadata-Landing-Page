======================================================================
NRA-Metadata - External Binaries Directory
======================================================================
Folder ini digunakan untuk menampung binary pihak ketiga yang dibutuhkan
oleh engine media processor:

1. ExifTool (Wajib untuk Metadata Injection):
   - Letakkan file: exiftool.exe
   - Unduh dari: https://exiftool.org

2. Ghostscript (Wajib untuk Preview Vektor EPS/AI):
   - Letakkan binary command-line: gswin64c.exe
   - Atau pastikan Ghostscript terinstal di Program Files sistem.

3. FFmpeg (Opsional untuk Ekstraksi Frame Video MP4/MOV):
   - Letakkan file: ffmpeg.exe
   - Unduh dari: https://ffmpeg.org
======================================================================
