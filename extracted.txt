### 🐛 Bug 6: Phantom Success & Pre-emptive Rate Limits
* **Symptom:** The script abandoned successfully generated images if Canva displayed a pre-emptive cooldown toast (e.g., "Try again in 3:00") intended for the *next* request.
* **Root Cause:** The script treated any rate limit toast as an absolute failure of the current prompt, immediately aborting the polling/download phase to go to sleep.
* **Solution:** Engineered a "Unified Parallel State Machine". The script now records the toast time but continues polling for 90 seconds.
